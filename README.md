# Tm.English 2018

Mobile and desktop app, developed in 2018.

Generate and scan QR codes used as “coupons” for English classes:
- View an overview of scheduled and completed classes.
- Scan coupons to register for a lesson.
- Generate QR codes containing AES-encrypted data.

## Tech stack
Mobile app (Android): 
- Xamarin.Forms 
- .NET Standard 1.4
- SQLite, MVVMLight, ZXing.NET

Desktop app (Windows)
- .NET Framework v4.6.1 (C# WinForms)
- DevExpress Reporting
